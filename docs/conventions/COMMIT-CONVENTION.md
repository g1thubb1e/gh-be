### 커밋 컨벤션
  {작업대분류}: {작업내용 요약}

  - {내용 1}
  - {내용 2}
  ...
  

* 작업 대분류 관련

  * feat
    * 신규 기능 개발
    * 표면적으로 기능에 변화가 없어도, 기존에 없던 로직이 추가되는 경우

  * fix
    * 버그로 인해 수정을 진행하는 경우
    * 기획 변경이나 프론트 요청 등등으로 작업 진행하는 경우에는 fix 대신 feat 사용

  * refactor
    * 기능 변화 없고, 로직이 추가되지 않으니 기존 코드를 수정하는 작업

  * chore
    * 의존성 추가
    * 환경변수 관련 작업
    * 설정 관련 작업 (yml, config 등등)

  * docs
    * 스웨거 작성
    * gitignore 업데이트
    * (필요한 경우) md 파일 업데이트

  * hotfix
    * 메인/디벨롭에 바로 푸시하는 경우에만 사용


### ex
chore: 프론트엔드 배포 관련 부분 주석처리
feat: jwt 토큰 발급 및 검증 기능 구현
refactor: adr 협의한대로 폴더구조 변경
