# Project

## 1. 프로젝트 개요

이 프로젝트는 **GitHub 저장소를 시각화하고, AI로 탐색할 수 있게 만드는 서비스**다.

텍스트와 폴더 구조만으로는 파악하기 어려운 저장소를 대상으로,
시각화, 로그북, AI 질의응답 기능을 제공하여
프로젝트의 구조, 기술 스택, 활동성, 주요 기능을 더 빠르게 이해할 수 있도록 돕는 것을 목표로 한다.

현재 제품 방향은 여러 저장소를 추천하거나 비교하는 서비스가 아니라,
**선택된 하나의 GitHub 저장소를 깊게 분석하고 탐색하는 서비스**다.

---

## 2. 해결하려는 문제

GitHub 저장소를 처음 접하는 개발자는 다음과 같은 어려움을 겪는다.

- 폴더 구조와 텍스트만으로는 전체 아키텍처를 한눈에 파악하기 어렵다.
- 저장소의 인기도, 활동성, 기술 스택을 확인하기 위해 여러 화면을 직접 확인해야 한다.
- 특정 기능이 어느 파일이나 디렉터리에 구현되어 있는지 찾기 어렵다.
- README만으로는 실제 구현 구조, 주요 로직, 기술 스택을 충분히 이해하기 어렵다.

이 프로젝트는 이러한 문제를 **시각화**와 **AI 기반 코드 탐색**으로 해결한다.

---

## 3. 핵심 기능

### 3.1 회원 및 프로필

사용자는 GitHub 계정을 기반으로 서비스에 가입하고,
자신의 프로필과 기술 스택 정보를 관리할 수 있다.

#### 구현 기능

- GitHub OAuth 기반 회원가입
- GitHub OAuth 로그인
- 로그인 사용자 프로필 생성
- 내 프로필 조회
- 내 프로필 편집
- 기술 스택 편집
- 프로필 공개 여부 설정
- 활동 통계 표시
  - 저장소 수
  - 스타 수
  - 최근 활동 여부 등
- 프로필 영역의 기술 스택 분포 표시

---

### 3.2 레포 데이터 수집 및 분석

서비스는 선택된 GitHub 저장소를 분석하기 위해
저장소의 메타데이터, 디렉터리 구조, README, 설정 파일, 의존성 파일, 최근 활동 정보를 수집한다.

#### 구현 기능

- 저장소 기본 정보 수집
  - 저장소명
  - owner
  - 설명
  - 대표 언어
  - stars
  - forks
- 디렉터리 구조 파싱
  - GitHub Tree API 등을 활용한 트리 구조 수집
- README 기반 프로젝트 개요 분석
- 설정 파일 기반 기술 스택 분석
  - `build.gradle`
  - `pom.xml`
  - `package.json`
  - 기타 주요 설정 파일
- 실행 및 사용 방법 파악
  - 핵심 엔트리 파일 식별
  - 주요 설정 파일 식별
- 스타 그래프 정보 수집
- 최근 커밋 및 활동 정보 수집
- 미해결 이슈 정보 수집 및 요약
- 열린 PR 정보 수집 및 요약
- 마지막 분석 시점 대비 변경사항 감지
  - 변경된 파일/폴더 목록 추출
  - 변경 범위가 시각화 또는 AI 응답에 영향을 주는지 판단
- 에이전트 답변 생성을 위한 데이터 파싱 및 저장
  - README
  - 설정 파일
  - 의존성 파일
  - 디렉터리 구조

---

### 3.3 로그북 및 저장소 요약

로그북은 사용자가 저장소를 본격적으로 탐색하기 전에
해당 저장소가 어떤 프로젝트인지 빠르게 파악할 수 있도록 돕는 요약 정보다.

#### 구현 기능

- 저장소 개요 제공
- 프로젝트 주요 기능 요약
- 기술 스택 요약
- 최근 활동 정보 제공
- 스타, 이슈, 포크 등 주요 지표 제공
- 미해결 이슈 및 열린 PR 요약
- AI 한 줄 요약 제공
- 로그북 조회 기능

---

### 3.4 저장소 시각화

저장소 시각화는 GitHub 저장소를 행성 또는 다이어그램 형태로 표현하여,
사용자가 저장소 구조와 활동성을 직관적으로 이해할 수 있도록 하는 기능이다.

#### 구현 기능

- 저장소를 하나의 행성 오브젝트로 표현
- 대표 언어 또는 주요 기술 스택 기반 테마 적용
- 행성 주변 요소 시각화
- 저장소 색상 시각화
- 활동성 기반 색상 표현
  - Active: 최근 활동이 많은 코드 또는 구조
  - Dormant: 오래 수정되지 않은 코드 또는 구조
- 최근 커밋 기준 활동성 표시
- 레포 확대
- 레포 회전
- 다이어그램 조회
- 다이어그램 클릭 시 연결된 GitHub 주소로 이동
- AI 코드 탐색 결과와 연결된 줌인 경험 제공

---

### 3.5 AI 레포 에이전트

AI 레포 에이전트는 사용자가 저장소를 직접 전부 읽지 않아도
질문을 통해 저장소의 개요, 기능, 기술 스택, 구현 위치를 탐색할 수 있게 하는 기능이다.

#### 구현 기능

- 레포 개요 질의응답
  - 예: “이 저장소는 어떤 서비스인가?”
- 기능 목록 질의응답
  - 예: “어떤 기능들이 구현되어 있는가?”
- 기능 위치 질의응답
  - 예: “로그인 기능은 어느 파일이나 디렉터리에 있는가?”
- 기술 스택 질의응답
  - 예: “어떤 프레임워크, DB, 배포 관련 스택을 사용하는가?”
- 구체적 구현 방식 질의응답
  - 예: “인증은 JWT 방식인가, OAuth 방식인가?”
  - 예: “프로젝트 특유의 비즈니스 로직은 어떻게 동작하는가?”
- 답변 근거 파일/디렉터리 제시
  - AI 답변에 사용된 관련 파일
  - 관련 디렉터리
  - 구조적 단서

#### 답변 원칙

AI 레포 에이전트는 가능한 경우 답변과 함께 근거를 제공해야 한다.

- README만 보고 구현 여부를 단정하지 않는다.
- 설정 파일, 엔트리 포인트, 실제 코드 위치를 함께 확인한다.
- 확실하지 않은 내용은 `추정`, `추가 확인 필요`, `미구현`을 구분한다.
- 답변에는 가능한 한 관련 파일 또는 디렉터리를 함께 제시한다.

## 4. 현재 범위 밖

아래 기능은 현재 기본 구현 범위에 포함하지 않는다.

- 여러 저장소를 비교하거나 추천하는 기능
- 인기 레포 랭킹 또는 탐색 기능
- 레포 전시 기능
- 대표 레포 강조 기능
- 커뮤니티 기능
- 레포 티어 경쟁 기능
- 친구 또는 그룹 기반 경쟁 기능
- 저장소 성격 MBTI 같은 부가 해석 기능
- 분석 결과를 README에 자동 삽입하는 기능
- Contributor별 수정 범위 시각화
- 기간 필터 기반 시각화
- 브랜치/이슈/커밋 흐름 자체를 별도 시각화하는 기능
- “Spring Boot 기반 인기 repo 보여줘”와 같은 멀티 레포 AI 탐색 기능
